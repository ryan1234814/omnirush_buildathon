# Brag Plan: Omnirush — 60s feature tour

## What is this app?
Omnirush is a one-click research agent: type a topic, watch the pipeline plan, search, extract, rank and synthesize in a live mission-control view, then get a professional report with deterministic inline citations, an integrity badge, and nine export formats. After the run, you can research gaps in a second round, ask grounded follow-ups, compare runs, schedule recurring reports, and get notified when they finish.

## The angle
Research agents usually ask for trust. Omnirush shows receipts. This cut keeps the fast, tactile mission-control tour, then stays long enough to show the whole post-report toolkit: gap rounds, follow-up chat, run diffing, schedules, nine export formats, and delivery notifications.

## Hook (first 2-3 seconds)
**ASK THE SYSTEM ANYTHING.** Giant ink type, a citation-backed run already loaded beside it. No windup.

## Key moments
- The pipeline lighting up: Plan → Search → Extract → Rank → Synthesize → Render with real telemetry.
- The report writing itself: **US$2.01B in 2026**, **33.1% CAGR**, each number carrying a `[n]` citation pill.
- The integrity check: `[9]` stamped **UNKNOWN SOURCE**, then **CITATION REMOVED**, badge settles on **26 VALIDATED / 1 HALLUCINATED REMOVED**.
- **Research round 2:** coverage review finds a regulatory gap, then runs a second search round inside the same `MAX_SEARCH_CALLS` budget.
- **Follow-up chat:** "What changed since last year?" answered from the cached citation registry with `[2] [4]`.
- **Compare runs:** four section changes plus source churn, `6 → 7`.
- **Schedules:** weekly/daily/once runs, one-time auto-disables after it fires.
- **Exports:** PDF, Markdown, HTML, Plain text, JSON, Executive summary, Blog post, LinkedIn digest, Marp slides.
- **Notifications:** in-app, webhook, email delivery after the run completes.
